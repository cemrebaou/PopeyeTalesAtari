# Popeye Tales (Atari)

DuckTales tarzı Phaser 3 platform oyunu (mobil öncelikli, dokunmatik tuşlu).
Görseller dosyadan yüklendiği için `index.html` çift tıklayarak değil bir web adresinden açılmalı
(GitHub Pages, raw.githack.com veya depo kökünde `python3 -m http.server`).

Klasör yapısı, kontroller, mekanikler, bölüm tasarımı ve araçlar: **`OYUN.md`**.
